# Multi-source disease, drug, and protein evidence

The example is an MCP tool-chain illustration, not a therapeutic conclusion.

A client may retrieve `map_disease_drug_landscape` for an exact MONDO
disease identifier, `assess_target_druggability` for a UniProt target,
and `analyze_structural_confidence` for that protein's AlphaFold DB
prediction.

Source-reported indications, drug mechanisms, sequence/target identities,
and predicted coordinates are distinct evidence objects. A predicted
structure does not independently validate drug binding, fusion-protein
conformation, resistance, or treatment efficacy.

Previously captured numerical and clinical narratives are no longer
presented as current MCP output. Query live providers and inspect exact
source identifiers and provenance for research use.
